## ✨ Features

### 📷 Image Metadata Extractor
- Extract EXIF data from images
- Camera make, model, lens
- Date & time taken
- Shutter speed, aperture, ISO, focal length
- GPS location with interactive map
- Software used for editing
- Artist & copyright info

### 🔐 Password Strength Checker
- Real-time strength analysis
- 5-point security check
- Color-coded strength bar (Weak / Medium / Strong)
- Strong password generator (16 characters)
- One-click copy

### #️⃣ Hash Generator
- SHA-1 hash generation
- SHA-256 hash generation
- Uses native Web Crypto API
- One-click copy for each hash

### 🔤 Base64 Encoder/Decoder
- Encode text to Base64
- Decode Base64 to text
- One-click copy

- 📺 **Scanline** — moving green line
- 💚 **Pulse Glow** — container breathing effect
- 🔴 **Terminal Dots** — blinking window controls
- ⚡ **Button Glow** — hover effects

## 🛠️ Tech Stack

- **HTML5** — structure
- **CSS3** — animations, hacker theme
- **Vanilla JavaScript** — all logic
- **Canvas API** — matrix rain effect
- **Web Crypto API** — hash generation
- **FileReader API** — image reading
- **exif-js** — EXIF metadata extraction
